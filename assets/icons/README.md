# Third-party marks

## Kali Linux dragon logomark

`kali-dragon.svg` is the official Kali Linux dragon logomark (black, transparent), copied unmodified from the [Kali Linux press pack](https://gitlab.com/kalilinux/documentation/press-pack) (`Kali/Logomark/kali-dragon-black.svg`).

It appears in the “How Gateforge works” figure to identify [Kali Linux](https://www.kali.org/) and the Kali tools stage (nmap, nuclei, peirates, and trivy). The mark is not the Gateforge logo and does not imply that OffSec or the Kali project endorse this repo.
